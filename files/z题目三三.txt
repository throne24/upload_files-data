(1)开启服务
systemctl enable postfix
systemctl restart postfix

(2)修改配置文件 文件有就改 没有就加上
vi /etc/postfix/main.cf
只需要找到相应的变量修改即可。注意不能在文档中
同时存在两个生效的相同变量

（#）mydestination = $mydomain, $myhostname 
（#）mydomain = wyulinuxos.com 
添加）myhostname = dns.wyulinuxos.com 
mynetworks = 172.24.90.0/24 
（疑似#）myorigin = $mydomain 
（#）inet_interfaces = all	
relay_domains = wyulinuxos.com 
virtual_alias_domains = linux.com, wyulinuxos.com 
virtual_alias_maps = hash:/etc/postfix/virtual

#请确保 inet_interfaces = localhost 失效 

(3)
useradd tom

vi /etc/postfix/virtual
加上
@linux.com              @wyulinuxos.com

保存退出：
postmap	/etc/postfix/virtual
systemctl restart postfix

vi /etc/aliases
加上：
all:	tom,jerry

(4)配置 cyrus-imapd 服务
vi /etc/postfix/main.cf 
启用如下内容（将句前“#”去掉）
mailbox_transport = lmtp:unix:/var/lib/imap/socket/lmtp

退出；

systemctl start cyrus-imapd
systemctl enable cyrus-imapd

打开 Foxmail 配置之前，必须让您的 Windows 电脑认识 mail.wyulinuxos.com 这个域名，否则 Foxmail 绝对连不上服务器。
在 Windows 搜索栏输入 记事本，右键点击“记事本”，选择 “以管理员身份运行”。

在记事本里点击“文件” -> “打开”，找到路径：C:\Windows\System32\drivers\etc\

右下角把“文本文档 (.txt)”改成“**所有文件 (.*)**”，然后双击打开 hosts 文件。

在文件的最下面，另起一行，输入：

172.24.82.1    mail.wyulinuxos.com
