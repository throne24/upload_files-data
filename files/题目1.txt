3.修改区域配置文件
#vi /etc/named.rfc1912.zones
在文件末尾添加正向和反向区域：

zone "wyulinuxos.com" IN {
        type master;
        file "data/wyulinuxos.com.zone";
        allow-update { none; };
};

zone "82.24.172.in-addr.arpa" IN {
        type master;
        file "data/172.24.82.arpa";
        allow-update { none; };
};


4.创建正向区域文件
cp /var/named/named.localhost /var/named/data/wyulinuxos.com.zone
vi /var/named/data/wyulinuxos.com.zone

写入以下内容：
$TTL 1D
@   IN SOA  dns.wyulinuxos.com. admin.wyulinuxos.com. (
                    0   ; serial
                    1D  ; refresh
                    1H  ; retry
                    1W  ; expire
                    3H )    ; minimum
    IN NS   dns.wyulinuxos.com.
dns IN A    172.24.82.1
www IN A   172.24.82.1
samba IN A   172.24.82.1
ftp IN A   172.24.82.1
mail IN A  172.24.82.1
course IN A 172.24.82.201
@   IN MX 10 mail4.wyulinuxos.com.


5.创建反向区域文件 
cp /var/named/named.localhost /var/named/data/172.24.82.arpa
vi /var/named/data/172.24.82.arpa

写入以下内容：
$TTL 1D
@   IN SOA  dns.wyulinuxos.com. admin.wyulinuxos.com. (
                    0   ; serial
                    1D  ; refresh
                    1H  ; retry
                    1W  ; expire
                    3H )    ; minimum
    IN NS   dns.wyulinuxos.com.
1   IN PTR  dns.wyulinuxos.com.
1   IN PTR  www.wyulinuxos.com.
1   IN PTR  samba.wyulinuxos.com.
1   IN PTR  ftp.wyulinuxos.com.
1   IN PTR  mail.wyulinuxos.com.
201 IN PTR  course.wyulinuxos.com.
