【1】给 ens33 加虚拟主机地址
----------------------------------------------------------------
ip addr add 172.24.82.201/24 dev ens33

ip -4 addr show ens33 | grep 201
  → 应看到 inet 172.24.82.201/24



【2】建站点目录和日志目录（必须先建）
----------------------------------------------------------------
mkdir -p /var/www/course /etc/httpd/logs/course
echo '<h1>course.wyulinuxos.com</h1>' > /var/www/course/index.html
touch /etc/httpd/logs/course/access_log /etc/httpd/logs/course/error_log
chown -R apache:apache /var/www/course /etc/httpd/logs/course

【3】写虚拟主机
----------------------------------------------------------------
vi /etc/httpd/conf/httpd.conf
粘贴下面全部内容：

<VirtualHost 172.24.82.201:80>
    ServerName course.wyulinuxos.com
    DocumentRoot "/var/www/course"
    ErrorLog /etc/httpd/logs/course/error_log
    CustomLog /etc/httpd/logs/course/access_log combined
    <Directory "/var/www/course">
        Require all granted
    </Directory>
</VirtualHost>

  Esc
  :wq
检查有没有写重：
grep -c 'VirtualHost 172.24.82.201' /etc/httpd/conf/httpd.conf
  → 只应该是 1


【4】检查并启动
----------------------------------------------------------------
httpd -t
  → 必须输出 Syntax OK

systemctl enable httpd
systemctl restart httpd
systemctl is-active httpd
  → active


【5】测试（Linux 侧，题目要求能用 wget）
----------------------------------------------------------------

wget -O - http://course.wyulinuxos.com
  → 输出 <h1>course.wyulinuxos.com</h1>

tail -2 /etc/httpd/logs/course/access_log
→ 输出应形如：
    172.24.82.1 - - [日期] "GET / HTTP/1.1" 200 31 "-" "Wget/1.14 (linux-gnu)"
